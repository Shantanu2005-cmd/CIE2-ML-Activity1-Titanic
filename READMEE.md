# CIE 2 – Machine Learning
## Activity 1: Dataset Preparation Using Titanic Dataset

### 1. Introduction
This project is completed as part of the Machine Learning CIE 2 activity. The objective is to inspect a dataset, identify data-quality issues, perform Exploratory Data Analysis (EDA), and prepare a cleaned dataset for future machine learning tasks.

### 2. Dataset Information
- **Dataset Name:** Titanic Passenger Dataset
- **Dataset Source:** [Titanic Dataset – GitHub](https://github.com/datasciencedojo/datasets/blob/master/titanic.csv)
- **File Format:** CSV
- **Original Rows:** 891
- **Original Columns:** 12

### 3. Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### 4. Activities Performed
1. Dataset selection and loading.
2. Dataset inspection and understanding.
3. Identification of numerical and categorical columns.
4. Missing-value analysis and handling.
5. Duplicate and consistency checks.
6. Exploratory Data Analysis (EDA).
7. Data visualization.
8. Categorical feature encoding using One-Hot Encoding.
9. Numerical feature scaling using StandardScaler.
10. Saving the prepared dataset as a CSV file.

### 5. Files Included
- Google Colab Jupyter Notebook (`.ipynb`)
- Prepared Titanic Dataset (`titanic_prepared.csv`)

### 6. Conclusion
The Titanic dataset was successfully inspected, cleaned and prepared for future machine learning workflows. Missing values were handled, duplicate records and category consistency were checked, visualizations were created, categorical variables were encoded, and numerical features were standardized. The final prepared dataset was exported as a CSV file.
